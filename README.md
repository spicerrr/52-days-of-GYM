# 52 дня качка · анатомия усилия

![Project](https://img.shields.io/badge/project-data%20art-7B61FF?style=flat-square) ![Domain](https://img.shields.io/badge/domain-fitness-0E7490?style=flat-square) ![Format](https://img.shields.io/badge/format-interactive%20web-238636?style=flat-square)

**Интерактивная визуализация тренировочного цикла 4 февраля — 26 марта 2026 года.** Исходный материал — логи Strong: даты, упражнения, рабочие веса, подходы и изменение поддержки в подтягиваниях. Проект исследует ритм тренировок и способы представления последовательности занятий в визуальной форме.

**[Открыть проект локально](#запуск) · [Исходный интерфейс](./index.html)**

---

## Что можно посмотреть

| Раздел | Содержание |
|:--|:--|
| Календарь | Визуализация тренировочных дней и календарное представление цикла |
| Тело | Интерактивное представление работы с телом |
| Подтягивания | Изменение поддержки и ход выполнения упражнения |
| Прогресс в весах | Изменения рабочих весов в течение цикла |
| Архив | Дополнительные материалы и представления |

Навигация по этим разделам реализована внутри страницы. Числовые показатели относятся к зафиксированному периоду, а не к текущим тренировочным результатам.

## Технологическая реализация

- `index.html` — интерфейс, стили и сценарии страницы;
- `assets/` — локальные графические и другие ресурсы;
- HTML / CSS / JavaScript — структура, оформление и взаимодействия;
- p5.js и `model-viewer` — внешние библиотеки, подключаемые через CDN.

Проект представляет **дата-арт и интерактивную визуализацию**, а не промышленную информационную систему или кейс системного анализа.

## Запуск

1. Клонировать репозиторий или скачать его содержимое.
2. Открыть файл `index.html` в браузере.
3. Для загрузки библиотек, подключаемых через CDN, потребуется доступ к сети.

Если ограничения браузера препятствуют загрузке локальных ресурсов, запустить простой HTTP-сервер из корня репозитория:

```bash
python3 -m http.server 8000
```

Затем открыть `http://localhost:8000`.
